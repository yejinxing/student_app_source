# 学生信息管理系统

## 🎯 项目概述

学生信息管理系统是一个功能强大的桌面应用程序，旨在帮助学校、培训机构或企业高效管理学生信息。该系统提供了Excel转Word文档工具和考生照片重命名功能，支持多种图片格式转换，界面美观现代，操作简单直观。

## ✨ 核心功能

### 1. Excel转Word文档工具
- 支持将包含学生信息的Excel文件转换为格式化的Word文档
- 自动生成标准化的学生信息表格
- 可自定义输出格式和样式
- 支持批量处理，提高工作效率

### 2. 考生照片重命名工具
- 自动匹配Excel数据与照片文件
- 支持多种图片格式转换（JPG、PNG、GIF等）
- 智能字段映射，支持自定义字段选择
- 实时进度显示和详细日志记录
- 支持中断和恢复功能

### 3. 系统特性
- 现代化的用户界面设计
- 响应式布局，适配不同屏幕尺寸
- 实时状态反馈和错误处理
- 完整的日志记录和进度追踪
- 跨平台支持（Windows、macOS、Linux）

## 📦 安装和运行

### 环境要求
- Node.js 14.0或更高版本
- npm或yarn包管理器

### 安装依赖
```bash
npm install
```

### 开发模式运行
```bash
npm start
```

### 打包应用程序
```bash
npm run build
```

## 🔧 使用说明

### Excel转Word文档工具
1. 打开应用程序
2. 点击"Excel 转 Word"功能
3. 选择包含学生信息的Excel文件
4. 点击"开始转换"
5. 等待转换完成，系统会自动打开输出文件夹

### 考生照片重命名工具
1. 选择"照片重命名"功能
2. 选择包含学生信息的Excel文件
3. 设置原始图片目录和输出目录
4. 选择输出格式
5. 点击"开始处理"
6. 查看处理进度和日志
